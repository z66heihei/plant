隐私政策

生效日期：2026年2月12日

欢迎您使用“草木知”（以下简称“本应用”）。我们非常重视您的隐私保护。 本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。

1. 我们收集的信息

为了向您提供植物识别服务及相关功能，我们需要获取以下权限和信息：

1.1 相机权限

当您使用“拍照识别”功能时，我们需要获取您的相机权限，以便您拍摄植物照片进行识别。 我们不会在未经您允许的情况下拍摄照片或录制视频。

1.2 相册（照片库）权限

当您选择从相册上传图片进行识别时，我们需要访问您的相册权限。 我们仅会读取您选择上传的那张图片，不会扫描或读取您相册中的其他内容。

1.3 设备信息与广告标识符

为了提供广告服务，我们可能会收集您的设备信息（如设备型号、操作系统版本、设备设置、 唯一设备标识符等）以及广告标识符（IDFA）。

2. 第三方 SDK 的使用

为了提供更好的服务和商业化运营，我们接入了第三方合作伙伴的 SDK。 这些第三方 SDK 可能会收集您的个人信息：

2.1 穿山甲广告 SDK（Bytedance）

  • 使用目的：为您提供个性化的广告展示
  • 收集信息类型：设备信息（设备型号、操作系统版本、设备设置、MAC 地址、IMEI、 Android ID、IDFA、OAID 等）、应用列表信息、网络信息（IP 地址、WiFi 信息、 基站信息等）、位置信息（粗略位置）
  • 隐私政策链接： https://www.csjplatform.com/privacy/partner

2.2 优量汇广告 SDK（Tencent）

  • 使用目的：为您提供广告服务
  • 收集信息类型：设备信息、网络信息、位置信息等
  • 隐私政策链接： https://e.qq.com/dev/help_detail.html?id=5333

3. 信息的使用

3.1 核心服务

我们收集的图片信息仅用于通过算法模型识别植物名称及相关信息。

3.2 改善体验

我们可能会收集非个人身份的统计数据（如识别成功率、App 崩溃日志）， 用于优化产品性能和修复故障。

3.3 广告服务

我们使用收集到的设备信息和广告标识符，通过第三方广告平台向您展示您可能感兴趣的广告。

4. 信息披露与共享

我们承诺不会将您的个人信息出售、出租或交易给任何第三方。除非：

  • 获得您的明确授权
  • 法律法规要求或政府部门的强制性命令
  • 与上述第三方 SDK 合作伙伴共享必要的信息以提供服务

5. 数据安全

我们采取合理的安全措施（包括技术手段和管理流程）来保护您的信息安全， 防止数据遭到未经授权的访问、公开披露、使用、修改、损坏或丢失。

6. 变更通知

我们可能会适时修订本隐私政策。如果发生重大变更， 我们会在 App 内通过弹窗或公告形式通知您。
